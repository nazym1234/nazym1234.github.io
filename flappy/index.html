À propos de cette version +

Le code OCaml du dépôt est compilé pour le navigateur avec js_of_ocaml. Cette adaptation ajoute le moteur Engine absent du dépôt, l’affichage web, la pause, le redémarrage et les commandes tactiles.

L’oiseau (), les tuyaux et les règles de déplacement reprennent le prototype textuel. Le départ est dégagé pour éviter une collision immédiate ; la progression mesure la distance parcourue.
